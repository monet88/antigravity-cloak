## `ProtectedAGY` vs `User-Agent` Brand Divergence (`#69`)

- **As of `monet88/antigravity-cloak@c864f7b` (`2026-11-28`, superseded on `2026-11-28` by `monet88/antigravity-cloak@14ca489`), `ProtectedAGY` skipped brand rewriting on conversation turns:** In [internal/cloak/handlers.go](../../internal/cloak/handlers.go), `handleProtectedAGY` ran `rewriteProtectedBrand` (which in [internal/cloak/brand.go](../../internal/cloak/brand.go) visited only top-level `system`, `system`/`developer` messages, and `tools[]` prose), then `sanitizeOMPPrompt`, then `rewriteOMPConversationProse(rootMap, nil, proseCloak)`. Passing `nil` mappings left `role: "tool"`, Anthropic `tool_result` text blocks, `user` `<system-reminder>` spans, and `assistant` `text`/`thinking` blocks without brand rewriting, diverging from the `User-Agent: omp/...` path in [internal/cloak/tool_cloak.go](../../internal/cloak/tool_cloak.go).
- **Sentinel casing difference (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`):** `rewriteProtectedBrandText` in [internal/cloak/brand.go](../../internal/cloak/brand.go) routed mandatory OMP aliases through `protectedBrandSentinel` to terminal `"Antigravity"` (always capitalized, preserving `omp://` via `NotFollowedBy: "://"` and remapping `.omp` to `.gemini`), whereas the `User-Agent: omp/...` path mirrored lowercase casing (`omp` -> `antigravity`).
- **Superseded test pin (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`, superseded on `2026-11-28` by `monet88/antigravity-cloak@14ca489`):** `TestProtectedAGYCustomMappingsReachProse` in [internal/cloak/issue59_review_red_test.go](../../internal/cloak/issue59_review_red_test.go) previously asserted that custom brand words stayed verbatim in `assistant` and `tool_result` blocks; [ADR 0006](../adr/0006-omp-inbound-sanitization-surfaces-and-v19-presets.md#consequences) explicitly superseded those assertions for `#69`.
- **Parity landed (`2026-11-28`, `monet88/antigravity-cloak@14ca489`, PR `#72`):** `#69` extended `rewriteProtectedBrand` in [internal/cloak/brand.go](../../internal/cloak/brand.go) to rewrite **Machine-Generated Conversation Turns** (`role: "tool"`, Anthropic `tool_result` text blocks, and `assistant` `text`/`thinking` blocks) plus `<system-reminder>` **Harness-Authored Surface** spans inside `user` turns, matching `User-Agent: omp/...` with ABI-seam tests in [issue69_protected_agy_brand_parity_test.go](../../issue69_protected_agy_brand_parity_test.go).
- **Naming and tool-loop cleanup (`2026-11-28`, PR `#72` review pass after `monet88/antigravity-cloak@9cfb8df`):** Renamed `rewriteMachineConversationTurns` to `rewriteOMPConversationBrandTurns` so helper naming matched [GLOSSARY.md](../../GLOSSARY.md#request-surfaces) (distinguishing **Machine-Generated Conversation Turns** from `<system-reminder>` **Harness-Authored Surfaces**), and extracted shared `rewriteToolsProse` in [internal/cloak/tool_cloak.go](../../internal/cloak/tool_cloak.go) for brand, sanitization, and tool-description passes.

## Sanitization Surface and Ordering Traps (`#70`)

- **Narrow pre-`#70` sanitization scope (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`, superseded on `2026-11-28` by `monet88/antigravity-cloak@61834e9`):** `sanitizeOMPPrompt` in [internal/cloak/omp_prompt_sanitization.go](../../internal/cloak/omp_prompt_sanitization.go) visited only top-level `system` and `system`/`developer` messages (documented in [system-conventions-sanitization.md](../specs/system-conventions-sanitization.md#scope-and-ordering)), skipping `tools[]` descriptions, JSON Schema `description`/`title` fields, and `user` `<system-reminder>` spans.
- **Two `User-Agent: omp/...` ordering traps (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`, superseded on `2026-11-28` by `monet88/antigravity-cloak@61834e9`):** In `rewriteRequestBodyForClient` ([internal/cloak/tool_cloak.go](../../internal/cloak/tool_cloak.go)):
  1. `rewriteToolDescriptions` ran *before* `sanitizeOMPPrompt` and combined brand rewriting and tool-alias cloaking in one `rewriteDescriptiveText` pass, breaking strict `brand -> sanitize -> tool-alias prose` ordering on tool descriptions and schemas.
  2. `rewriteOMPConversationProse` ran *after* `sanitizeOMPPrompt` with non-nil `mappings`, which would apply brand rewriting *after* sanitization on `<system-reminder>` spans and risk clobbering sanitized replacements.
- **Reusable walkers (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`):** [internal/cloak/tool_cloak.go](../../internal/cloak/tool_cloak.go) already contained `rewriteToolProse` -> `rewriteSchemaTextFields` -> `rewriteSchemaValue` (skipping `schemaLiteralKeys` such as `const`/`enum`/`default`/`example`/`examples` while descending `schemaDictionaryKeys`) and `rewriteSystemReminderSpans` (handling multiple and unterminated `<system-reminder>` spans).
- **Shared Claude Code helper blast radius (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`):** `sanitizeSystemNewsURL` in [internal/cloak/issue55_agent_tier.go](../../internal/cloak/issue55_agent_tier.go) shared `rewritePromptTextContent` and `rewriteSystemDeveloperMessages` (`allowInputText=false`) for `claude_code`, so changes to those shared walkers required preserving Claude Code behavior.
- **Fixture impact (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`, superseded on `2026-11-28` by `monet88/antigravity-cloak@61834e9`):** `fiveRoleCarrierFixture` and `applyExpectedSanitization` in [internal/cloak/system_conventions_test.go](../../internal/cloak/system_conventions_test.go) previously expected `tools[]` descriptions and schema descriptions to remain unsanitized.
- **Expanded surfaces and strict ordering landed (`2026-11-28`, `monet88/antigravity-cloak@61834e9`, PR `#72`):** `#70` expanded **Inbound Sanitization** to `tools[].description`, JSON Schema `description`/`title`, and `<system-reminder>` spans while reordering `rewriteRequestBodyForClient` into strict `brand -> sanitize -> tool-alias prose` passes and adding [issue70_inbound_sanitization_surfaces_test.go](../../issue70_inbound_sanitization_surfaces_test.go).
- **Delimiter-tag corruption trap and fused single pass (`2026-11-28`, `monet88/antigravity-cloak@8c800d0`, PR `#72`):** Pre-push `ponytail-review` on `monet88/antigravity-cloak@61834e9` caught that a sanitization rule rewriting or stripping `<system-reminder>` tags prevented a second walker from locating the span for tool-alias cloaking. Commit `monet88/antigravity-cloak@8c800d0` fused `sanitize -> tool-alias` into one span pass inside `rewriteOMPConversationProse` (`internal/cloak/tool_cloak.go`).
- **Single atomic rule snapshot per request (`2026-11-28`, PR `#72` review pass after `monet88/antigravity-cloak@9cfb8df`):** Eliminated split-snapshot sanitization under concurrent `plugin.reconfigure` ([ADR 0001](../adr/0001-stream-session-manager-and-atomic-config.md)) by capturing `activeFilterConfig().ompSanitizationRules` once per request and passing that slice to both `sanitizeOMPPrompt` and `rewriteOMPConversationProse`, while renaming `sanitizeReminders` to `runOMPSanitization` in [internal/cloak/handlers.go](../../internal/cloak/handlers.go).

## Built-In Sanitization Preset Traps (`#71`)

- **Non-ASCII case-insensitive preset omission (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`, superseded on `2026-11-28` by `monet88/antigravity-cloak@9cfb8df`):** `ompSanitizationPreset` in [internal/cloak/omp_prompt_sanitization.go](../../internal/cloak/omp_prompt_sanitization.go) computed `asciiOnly` but omitted compiling `re` when `!caseSensitive && !asciiOnly`, unlike `buildOMPSanitizationRules` for operator entries. Because `ompRuleMatchLength` fell back to `if rule.re != nil`, any non-ASCII case-insensitive built-in preset (such as Unicode punctuation or em-dash strings) silently failed to match at `monet88/antigravity-cloak@c864f7b`.
- **Brand-before-sanitize and longest-match constraints (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`):** `sanitizeOMPPromptText` executed a single non-cascading left-to-right pass sorted by descending `len(match)`. Per [ADR 0006](../adr/0006-omp-inbound-sanitization-surfaces-and-v19-presets.md#decision), `#71` presets referencing `OMP` required both post-brand (`Antigravity`) and pre-brand (`OMP`) case-insensitive forms, and the `omp://` docs bullet required CRLF/LF bulleted forms ahead of the bare fallback.
- **Hardcoded preset count test (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`, superseded on `2026-11-28` by `monet88/antigravity-cloak@9cfb8df`):** [internal/clients/omp/spec_test.go](../../internal/clients/omp/spec_test.go) asserted `len(s.PromptSanitizations) != 5`, requiring an exact-count update alongside new v19.2.1 presets in [internal/clients/omp/spec.go](../../internal/clients/omp/spec.go) under `#71`.
- **v19.2.1 presets and non-ASCII regex unification landed (`2026-11-28`, `monet88/antigravity-cloak@9cfb8df`, PR `#72`):** `#71` added 8 preset groups (9 v19.2.1 patterns, 12 literal rules, 17 total built-in presets in [internal/clients/omp/spec.go](../../internal/clients/omp/spec.go)), unified `ompSanitizationPreset` and `buildOMPSanitizationRules` to compile anchored `(?i)^` prefix regexes for non-ASCII case-insensitive rules, updated [internal/clients/omp/spec_test.go](../../internal/clients/omp/spec_test.go) to assert 17 presets, and added ABI-seam coverage in [issue71_omp_v19_presets_test.go](../../issue71_omp_v19_presets_test.go).
- **Non-reversal invariant (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`, re-verified at `monet88/antigravity-cloak@9cfb8df`):** `HandleResponseIntercept` and `HandleStreamChunkIntercept` in [internal/cloak/handlers.go](../../internal/cloak/handlers.go) reversed only tool uncloak tables and `ompProtectedReverseTable` in [internal/clients/omp/spec.go](../../internal/clients/omp/spec.go), leaving **Inbound Sanitization** strictly one-way (see [CONTEXT.md](../../CONTEXT.md)).
