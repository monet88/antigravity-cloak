## `ProtectedAGY` vs `User-Agent` Brand Divergence (`#69`)

- **As of `monet88/antigravity-cloak@c864f7b` (`2026-11-28`), `ProtectedAGY` skipped brand rewriting on conversation turns:** In [internal/cloak/handlers.go](../../internal/cloak/handlers.go), `handleProtectedAGY` ran `rewriteProtectedBrand` (which in [internal/cloak/brand.go](../../internal/cloak/brand.go) visited only top-level `system`, `system`/`developer` messages, and `tools[]` prose), then `sanitizeOMPPrompt`, then `rewriteOMPConversationProse(rootMap, nil, proseCloak)`. - **Superseded test pin (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`):** `TestProtectedAGYCustomMappingsReachProse` in [internal/cloak/issue59_review_red_test.go](../../internal/cloak/issue59_review_red_test.go) previously asserted that custom brand words stayed verbatim in `assistant` and `tool_result` blocks; [ADR 0006](../adr/0006-omp-inbound-sanitization-surfaces-and-v19-presets.md#consequences) explicitly superseded those assertions for `#69`.

## Sanitization Surface and Ordering Traps (`#70`)

- **Narrow pre-`#70` sanitization scope (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`):** `sanitizeOMPPrompt` in [internal/cloak/omp_prompt_sanitization.go](../../internal/cloak/omp_prompt_sanitization.go) visited only top-level `system` and `system`/`developer` messages (documented in [system-conventions-sanitization.md](../specs/system-conventions-sanitization.md#scope-and-ordering)), skipping `tools[]` descriptions, JSON Schema `description`/`title` fields, and `user` `<system-reminder>` spans.
- **Two `User-Agent: omp/...` ordering traps (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`):** In `rewriteRequestBodyForClient` ([internal/cloak/tool_cloak.go](../../internal/cloak/tool_cloak.go)):
  1. `rewriteToolDescriptions` ran *before* `sanitizeOMPPrompt` and combined brand rewriting and tool-alias cloaking in one `rewriteDescriptiveText` pass, breaking strict `brand -> sanitize -> tool-alias prose` ordering on tool descriptions and schemas.
  2. `rewriteOMPConversationProse` ran *after* `sanitizeOMPPrompt` with non-nil `mappings`, which would apply brand rewriting *after* sanitization on `<system-reminder>` spans and risk clobbering sanitized replacements.
- **Reusable walkers (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`):** [internal/cloak/tool_cloak.go](../../internal/cloak/tool_cloak.go) already contained `rewriteToolProse` -> `rewriteSchemaTextFields` -> `rewriteSchemaValue` (skipping `schemaLiteralKeys` such as `const`/`enum`/`default`/`example`/`examples` while descending `schemaDictionaryKeys`) and `rewriteSystemReminderSpans` (handling multiple and unterminated `<system-reminder>` spans).
- **Shared Claude Code helper blast radius (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`):** `sanitizeSystemNewsURL` in [internal/cloak/issue55_agent_tier.go](../../internal/cloak/issue55_agent_tier.go) shared `rewritePromptTextContent` and `rewriteSystemDeveloperMessages` (`allowInputText=false`) for `claude_code`, so changes to those shared walkers required preserving Claude Code behavior.
- **Fixture impact (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`):** `fiveRoleCarrierFixture` and `applyExpectedSanitization` in [internal/cloak/system_conventions_test.go](../../internal/cloak/system_conventions_test.go) previously expected `tools[]` descriptions and schema descriptions to remain unsanitized.

## Built-In Sanitization Preset Traps (`#71`)

- **Non-ASCII case-insensitive preset omission (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`):** `ompSanitizationPreset` in [internal/cloak/omp_prompt_sanitization.go](../../internal/cloak/omp_prompt_sanitization.go) computed `asciiOnly` but omitted compiling `re` when `!caseSensitive && !asciiOnly`, unlike `buildOMPSanitizationRules` for operator entries. Because `ompRuleMatchLength` fell back to `if rule.re != nil`, any non-ASCII case-insensitive built-in preset (such as Unicode punctuation or em-dash strings) silently failed to match at `monet88/antigravity-cloak@c864f7b`.
- **Brand-before-sanitize and longest-match constraints (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`):** `sanitizeOMPPromptText` executed a single non-cascading left-to-right pass sorted by descending `len(match)`. Per [ADR 0006](../adr/0006-omp-inbound-sanitization-surfaces-and-v19-presets.md#decision), `#71` presets referencing `OMP` required both post-brand (`Antigravity`) and pre-brand (`OMP`) case-insensitive forms, and the `omp://` docs bullet required CRLF/LF bulleted forms ahead of the bare fallback.
- **Hardcoded preset count test (`2026-11-28`, `monet88/antigravity-cloak@c864f7b`):** [internal/clients/omp/spec_test.go](../../internal/clients/omp/spec_test.go) asserted `len(s.PromptSanitizations) != 5`, requiring an exact-count update alongside new v19.2.1 presets in [internal/clients/omp/spec.go](../../internal/clients/omp/spec.go) under `#71`.
